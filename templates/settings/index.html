NIDS & Feature Glossary

DoS (Denial of Service) An attack that attempts to render a machine or network resource unavailable to its intended users by flooding it with illegitimate connection requests.
Probe (Reconnaissance) Surveillance scans (e.g. nmap, ipsweep) where an adversary maps open ports and active services across a network before launching a directed exploit.
R2L (Remote to Local) An attack where an unauthorized remote user exploits weaknesses to gain local user privileges on a machine (e.g. password brute force).
U2R (User to Root) Privilege escalation where a user with non-privileged access executes an exploit (e.g. buffer overflow) to obtain root/superuser capabilities.
srv_count & serror_rate srv_count measures connections to the same port in a 2-second sliding window. serror_rate represents the percentage of those connections that encountered SYN handshake errors.
