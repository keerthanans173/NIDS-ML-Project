Raw Network Packet Capture (Experimental)

Experimental Feature

SentinelFlow is calibrated on the 41-feature NSL-KDD benchmark, which utilizes synthesized statistical connection window summaries (e.g., 2-second connection rates, host error ratios, service concentrations) rather than isolated raw Ethernet frames.

Prerequisites for Physical Raw Sniffing:

  • Administrator / elevated root privileges for raw socket bindings.
  • WinPcap / Npcap drivers installed on Windows host.
  • Real-time flow aggregation daemon to compute 2-second sliding connection windows (count, serror_rate, same_srv_rate).

To demonstrate live system operations safely without driver locks or elevated socket panics, please utilize Mode 3 (Live Replay Stream) or the Attack Simulator.
